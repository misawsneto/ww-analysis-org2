# G-ORG2-DOMAIN-001-SPEC001 — Bounded-context model requirements

**Goal:** G-ORG2-DOMAIN-001
**Version:** 1
**State:** active

## Requirements

### G-ORG2-DOMAIN-001-SPEC001-REQ001 — Preserve evidence layers

Generated UA/Graphify outputs remain unchanged. The curated model records the accepted source revision and evidence basis.

### G-ORG2-DOMAIN-001-SPEC001-REQ002 — Canonical context map

Publish eight product contexts, two edge contexts, and explicit infrastructure/shared-scope classifications.

### G-ORG2-DOMAIN-001-SPEC001-REQ003 — Context records

Each context record states purpose, boundary, owned concepts, invariants, consumed/published contracts, representative source paths, and non-ownership notes.

### G-ORG2-DOMAIN-001-SPEC001-REQ004 — Entity ownership

Publish one semantic owner for important identities and lifecycle concepts; projections/references must not silently become owners.

### G-ORG2-DOMAIN-001-SPEC001-REQ005 — Ubiquitous language

Record the major non-equivalences: Org Task/Work Item, Agent Org/Project Org/Cloud Org, Agent Session/Session Record, Workspace/Project/Repository, Agent Definition/Resolved Agent, Turn Intent/Dialog Turn, and Skill/Tool/MCP Server/Capability.

### G-ORG2-DOMAIN-001-SPEC001-REQ006 — Context relationships

Document semantic translation/contracts among configuration, execution, work, coordination, control, memory, provenance, collaboration, and edge contexts.

### G-ORG2-DOMAIN-001-SPEC001-REQ007 — Source mapping

Map logical contexts to representative implementation paths without claiming that source layout defines the boundary.

### G-ORG2-DOMAIN-001-SPEC001-REQ008 — Bounded verification

Run one deterministic structure/evidence verification and one model-consistency review. Do not enter iterative review loops unless a material defect is found.
